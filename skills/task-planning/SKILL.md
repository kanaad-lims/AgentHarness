# Task Planning

Use `write_todos` when a request has more than one deliverable or step,
whether or not tools are involved.

- List EVERY deliverable first, including direct-answer parts.
- Send the complete list on each update.
- Keep exactly one unfinished task `in_progress`; mark done as you go.
- Single-deliverable requests skip planning entirely.
